First public version of GPSLoggerKit, a native Swift reader for GPS logger file formats and logger protocols with
a common data model and GPX 1.1 output. This is an early release (pre-release): the API may still change in 0.x
minor versions.

**Platforms:** macOS 12+, iOS/iPadOS 27+ · Swift 6 · no dependencies · MIT license

**File formats (read):** NMEA 0183, GPX 1.0/1.1, IGC, Garmin FIT, TCX, Suunto SML (Ambit), KML/KMZ,
Columbus V-900 / Visiontac CSV, iBlue 747/757 CSV. Output: GPX 1.1.

**Logger protocols:** GNS 2000 / GNS 2000 plus (read and erase) over a `DeviceConnection` provided by the app.

**Processing:** GPS week rollover correction, waypoints as track, format detection, warnings for skipped or damaged
records, extensible format catalog (`FormatCatalog`).

Installation:

```swift
.package(url: "https://github.com/mytracks/GPSLoggerKit.git", .upToNextMinor(from: "0.1.0"))
```

The package was developed in [mytracks/gpsloader](https://github.com/mytracks/gpsloader); `PROVENANCE.md` lists the
sources of every format (clean-room, no GPL code).
